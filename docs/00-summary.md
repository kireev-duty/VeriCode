# Краткое описание подхода (промежуточная сдача)

**ФСП Талант** — веб-платформа подбора ИТ-специалистов с обратной механикой: категорию кандидата определяет
адаптивный тест, а работодатель сам выходит на кандидата с предложением и зарплатной вилкой.

## Механика тестирования

1. **Опрос:** отрасль, специализация, стек, три вопроса самооценки, предполагаемый грейд.
2. **Адаптивный тест (IRT 3PL + CAT)** на заявленный грейд, 10–18 заданий. Следующее задание выбирается по
   максимуму информации с балансом навыков по blueprint; при тесте по вакансии blueprint строится из её навыков.
3. **Задания — параметрические семейства:** 38 семейств, 92 калиброванные позиции. Структура и сложность
   фиксированы, данные генерируются. Ответ вычисляется исполнением кода, SQL-движком или точной моделью
   семантики, LLM для этого не нужна. У каждого кандидата свой экземпляр, поэтому слитый ключ бесполезен.
4. **Грейд** присваивается при P(θ ≥ порог) ≥ 0,6.
   - Не подтвердился — без понижения, сразу доступен тест на ступень ниже.
   - Подтвердился уверенно — 7 дней доступен тест на ступень выше.
   - Смена грейда — не чаще раза в 90 дней.
5. **Защита от утечек:** параметризация, рандомизированный отбор с лимитом семейства, CUSUM-детектор утечек
   по позициям, сигналы целостности без автоматических штрафов.
6. **Регулярные задания** от работодателей раз в неделю, оценка по прозрачной рубрике, индекс актуальности профиля.

## Механика подбора

1. Работодатель описывает потребность текстом. NLP извлекает специализацию, грейд, обязательный и желательный
   стек, формат, город и вилку.
2. Система рекомендует категории — целевую и соседние — и ранжирует кандидатов объяснимым скорингом:
   - стек, подтверждённый тестом, весит больше заявленного;
   - учитываются грейд, сила результата теста, ФСП, зарплата, формат и актуальность.

   У каждого кандидата есть «чипы» с плюсами и минусами.
3. Фильтры уточняют подборку без её потери, закреплённые кандидаты остаются в выдаче.
4. Приглашение:
   - анонимная карточка до согласия кандидата;
   - перед отправкой — проверка «вилка попадает в ожидания» без раскрытия суммы;
   - вилка обязательна;
   - квота 20 приглашений в неделю.
5. Принятие открывает контакты. Отказ — с причиной, и веса ранжирования компании адаптируются.
6. Дополнительно: классический отклик на вакансию, траст-скор работодателя, вебхуки для ATS.

## ФСП ID и достижения

- Привязка через OIDC (Keycloak, realm `fsp`) и сервис реестра по предложенному нами контракту.
- Сигнал ФСП = уровень × результат × давность × релевантность дисциплины, плюс разряд.
- ФСП поднимает кандидата внутри категории.
- Кандидат без истории ФСП не штрафуется.

## Валидация (синтетика с известной «скрытой истиной», 3000 кандидатов)

| Что проверяли | Результат |
|---|---|
| Грейд совпал с истинным | **77,5%** (самооценка — 63%); ошибка ≤ 1 грейда — 100% |
| Повторный тест на новых экземплярах | κ = **0,85** |
| Утечка ключа к 40% заданий: доля «нечестных» с повышенным грейдом | статичный тест **54%** → наш тест **0%** |
| Точность топ-10 подборки (P@10) | поиск по ключевым словам 0,63 → **наш скоринг 0,83** |
| Детектор утечек | 3,7% ложных срабатываний; 65–80% обнаружения |
